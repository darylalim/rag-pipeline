# CI quotas (values as of 1 September 2025)

These values replace the March 2024 quotas.

| Quota | Value |
| --- | --- |
| Concurrent jobs per repository | 20 |
| Job timeout | 30 minutes |
| Build cache per repository | 10 GB |
| Artifact retention | 14 days |

The job timeout was halved because long jobs were almost always hung ones. A
team that needs more can ask Platform for a temporary raise.
