# Glossary

- **Lane:** an origin and destination pair, such as Chicago to Dallas.
- **Scan:** a single carrier event about a shipment, such as a pickup or an
  arrival at a facility.
- **Dwell time:** how long a shipment stays at one facility between scans.
- **ETA drift:** the difference between the predicted and the actual arrival
  time.
- **Carrier ping:** a status request Tallowmere sends to a carrier's own API
  when no scan has arrived for 24 hours.
